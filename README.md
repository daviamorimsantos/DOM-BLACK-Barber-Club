# DOM BLACK - Projeto 2 do portfólio

Site demonstrativo de uma barbearia fictícia, criado para apresentar serviços de criação de sites.

## Publicar no GitHub
Crie um repositório, envie `index.html` e `style.css` e depois importe o repositório na Vercel.

## Observações
- O telefone usado no WhatsApp é fictício: 5517999999999.
- Nomes, preços, endereço e equipe são fictícios.
- As fotos são carregadas externamente.
- Antes de usar para um cliente real, substitua todos os dados demonstrativos.
